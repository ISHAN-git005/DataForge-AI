# ⚡ AutoRefine AI: Automated Data Sanitization & Dual-State EDA Engine

AutoRefine is a full-stack automated data preprocessing, anomaly mitigation, and exploratory profiling engine built with Python and Streamlit.

## Features
- **Adaptive Data Cleansing:** Resolves missing entries using distribution-aware strategies (mean/median/mode).
- **Outlier Mitigation:** Winsorization capping based on adjustable Interquartile Range (IQR).
- **Format Normalization:** Snake_case standardizing, whitespace trimming, date parsing, and type inference.
- **Dual-State Visual Profiling:** Side-by-side Plotly comparisons showing pre- and post-cleaning metrics.
- **Reproducible Audit Trail:** Detailed log recording every change and affected record.
